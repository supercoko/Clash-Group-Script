# Clash Verge Rev 用分组 全局扩展脚本

Chatgpt生成的覆盖原有分组的JS脚本

| 策略组 | 分流与默认选择 |
|---|---|
| 🤖 AI组 | Google 搜索与 AI 模式、Gemini、ChatGPT、Claude、Grok 等。可手动选节点 |
| 🌐 社媒组 | YouTube 及其视频 CDN、Instagram、X、Facebook 等。可手动选节点 |
| 🎮 下载组 | Steam 和 Epic 的下载 CDN。默认 `DIRECT`，可手动切换 |
| 🌍 外网组 | 迁移后的通用代理规则及剩余流量。可手动选节点 |
| 🇨🇳 国内组 | 国内域名、国内 IP 和局域网。默认 `DIRECT`，可手动切换 |
